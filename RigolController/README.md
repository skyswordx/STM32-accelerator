# STM32H7 DDS自动校准系统

## 系统概述

这是一个针对STM32H7开发板DDS输出功能的自动校准与测量系统。系统能够自动控制H7输出不同频率和幅度的信号，使用RIGOL示波器进行精确测量，并生成详细的校准报告。

## 硬件要求

1. **STM32H7开发板** - 带有DDS功能（AD9954）
2. **RIGOL示波器** - MSO2000A/DS2000A系列（IP: 192.168.1.3）
3. **RIGOL信号发生器** - （IP: 192.168.1.2，可选）
4. **USB转串口线** - 连接STM32H7（默认COM14）

## 文件说明

### 主要文件

- `RigolTest.py` - **完整校准程序**，包含全面的自动测量功能（需要示波器+信号发生器+H7）
- `simple_test.py` - **简化校准程序**，仅需示波器和H7的快速测试版本
- `quick_test.py` - **连接测试脚本**，验证设备连接状态
- `config.py` - 配置文件，包含所有系统参数
- `data_analysis.py` - 数据分析脚本，生成可视化报告
- `start.bat` - 启动器脚本，方便选择不同测试模式

### 配置文件

- `command.md` - STM32H7串口命令说明
- `MSO2000A&DS2000A_ProgrammingGuide_CN.pdf` - 示波器编程手册

## 使用方法

### 0. 启动器（推荐）

直接双击 `start.bat` 文件，选择相应的测试模式：

- **模式1**: 快速连接测试 - 验证设备连接状态
- **模式2**: 简化校准测试 - 仅需示波器+H7，适合日常验证
- **模式3**: 完整校准测试 - 全功能版本，需要所有设备
- **模式4**: 数据分析 - 分析已有的测试结果

### 1. 快速测试（推荐新用户）

首先运行简化版本确保基本功能正常：

```bash
python simple_test.py
```

这个版本提供多种测试模式：

1. **快速测试**: 10个预设测试点
2. **频率扫描**: 固定幅度下的频率范围测试
3. **幅度扫描**: 固定频率下的幅度范围测试  
4. **单点测试**: 测试特定频率和幅度

### 2. 连接验证

运行连接测试确保所有设备连接正常：

```bash
python quick_test.py
```

### 2. 配置参数

编辑 `config.py` 文件，修改以下参数：

```python
# 网络设备IP
OSCILLOSCOPE_IP = "192.168.1.3"
SIGNAL_GENERATOR_IP = "192.168.1.2"  # 仅完整版本需要

# 串口配置
SERIAL_PORT = "COM14"

# 测试范围
FREQ_START = 100        # 起始频率 (Hz)
FREQ_END = 1000000      # 结束频率 (Hz)
FREQ_STEP = 100         # 频率步进 (Hz)

AMP_START = 0.5         # 起始幅度 (V)
AMP_END = 3.0           # 结束幅度 (V)
AMP_STEP = 0.5          # 幅度步进 (V)
```

### 3. 运行完整校准（可选）

如果需要最全面的校准数据：

```bash
python RigolTest.py
```

程序将自动：
- 连接所有设备
- 按照配置的参数范围进行测试
- 对每个测试点进行精确测量
- 生成Excel格式的详细报告

### 4. 数据分析

校准完成后，运行数据分析脚本：

```bash
python data_analysis.py
```

程序会要求选择Excel文件，然后生成：
- 频率误差分析图
- 幅度误差分析图
- 误差分布统计图
- 3D误差可视化图
- 详细统计报告

## 测试规格

### 默认测试范围

- **频率范围**: 100Hz ~ 1MHz（步进100Hz）
- **幅度范围**: 0.5V ~ 3V（步进0.5V）
- **总测试点**: 60,000个（10,000频率点 × 6幅度点）

### 示波器设置

- **平均采样**: 2次
- **测量类型**: 频率 + 峰峰值
- **自动时基**: 根据频率自动调整
- **触发方式**: 正边沿触发

### STM32H7控制命令

```
SET:DDS_TYPE:9954      # 设置DDS类型为AD9954
SET:DDS_FREQ:1000      # 设置频率为1000Hz
SET:DDS_AMP:1.0        # 设置幅度为1.0V
```

## 输出文件

### Excel报告

- **原始数据表**: 包含所有测试点的详细数据
- **统计汇总表**: 按幅度分组的统计信息

### 分析报告

- `frequency_error_analysis.png` - 频率误差分析图
- `amplitude_error_analysis.png` - 幅度误差分析图
- `error_distribution.png` - 误差分布图
- `3d_error_analysis.png` - 3D误差分布图
- `statistics_report.txt` - 详细统计报告

## 误差分析指标

- **频率误差**: (测量值 - 设定值) / 设定值 × 100%
- **幅度误差**: (测量值 - 设定值) / 设定值 × 100%
- **统计指标**: 均值、标准差、最大误差

## 故障排除

### 常见问题

1. **串口连接失败**
   - 检查COM端口号是否正确
   - 确认STM32H7已正确连接并上电

2. **示波器连接失败**
   - 检查IP地址是否正确
   - 确认网络连接正常

3. **测量数据异常**
   - 检查示波器探头连接
   - 确认信号输出正常
   - 调整示波器量程设置

4. **程序运行缓慢**
   - 减少测试点数量
   - 调整延时参数

### 日志输出

程序运行时会输出详细的日志信息，包括：
- 设备连接状态
- 测试进度
- 测量结果
- 错误信息
