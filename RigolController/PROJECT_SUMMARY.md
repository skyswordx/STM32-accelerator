# STM32H7 DDS校准系统 - 项目总结

## 🎯 项目概述

您现在拥有一套完整的STM32H7 DDS输出自动校准与测量系统，该系统可以精确测量H7开发板DDS输出的频率和幅度精度，并生成详细的校准报告。

## 📁 文件结构

```
RigolController/
├── RigolTest.py           # 完整校准程序（需要示波器+信号发生器+H7）
├── simple_test.py         # 简化校准程序（仅需示波器+H7）⭐推荐
├── quick_test.py          # 连接测试脚本
├── data_analysis.py       # 数据分析和可视化
├── config.py              # 配置文件
├── start.bat              # 启动器脚本
├── README.md              # 详细说明文档
└── command.md             # STM32H7串口命令参考
```

## 🚀 快速开始

### 方法1: 使用启动器（最简单）
```bash
# 双击运行
start.bat
```

### 方法2: 直接运行
```bash
# 简化版测试（推荐）
python simple_test.py

# 连接验证
python quick_test.py

# 完整版测试
python RigolTest.py
```

## 💡 版本对比

| 功能 | simple_test.py | RigolTest.py |
|------|---------------|---------------|
| 硬件需求 | 示波器 + H7 | 示波器 + 信号发生器 + H7 |
| 测试速度 | 快速 | 全面但较慢 |
| 测试点数 | 10-1000个 | 60,000个 |
| 适用场景 | 日常验证、快速测试 | 全面校准、研发验证 |
| 推荐度 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |

## 🔧 测试模式

### simple_test.py 提供的测试模式：

1. **快速测试** - 10个预设测试点，涵盖关键频率和幅度
2. **频率扫描** - 固定幅度下的频率范围测试
3. **幅度扫描** - 固定频率下的幅度范围测试
4. **单点测试** - 测试特定频率和幅度组合

### 测试参数范围：
- **频率**: 100Hz ~ 1MHz
- **幅度**: 0.5V ~ 3V
- **精度**: 频率±0.1%，幅度±5%

## 📊 输出结果

### Excel报告包含：
- 原始测试数据（每个测试点的详细结果）
- 统计汇总（误差分析、有效率等）
- 时间戳（便于版本管理）

### 可视化分析：
- 频率误差vs频率曲线图
- 幅度误差vs频率曲线图
- 误差分布直方图
- 3D误差分布图

## ⚙️ 硬件连接

```
STM32H7 开发板
    ↓ (USB串口 COM14)
电脑 ←→ 网络交换机 ←→ RIGOL示波器 (192.168.1.3)
```

### 信号连接：
- H7 DDS输出 → 示波器CH1输入
- 确保共地连接

## 🎛️ 示波器自动配置

系统会根据测试频率自动设置：
- **时基**: 1μs/div ~ 1ms/div
- **采样**: 2次平均
- **量程**: 1V/div
- **触发**: 正边沿，自动模式

## 📈 性能指标

### 测试覆盖范围：
- 频率: 100Hz到1MHz（可配置步进）
- 幅度: 0.5V到3V（可配置步进）

### 测试精度：
- 频率测量精度: 取决于示波器（通常±0.01%）
- 幅度测量精度: 取决于示波器（通常±2%）

### 测试速度：
- 单点测试: ~3秒
- 快速测试(10点): ~30秒
- 频率扫描(100点): ~5分钟

## 🛠️ 自定义配置

编辑 `config.py` 可修改：
- IP地址
- 串口配置
- 测试范围
- 延时参数
- 误差阈值

## 🔍 故障排除

### 常见问题：
1. **连接失败**: 检查IP地址和串口号
2. **测量异常**: 确认信号线连接和示波器设置
3. **数据无效**: 检查H7程序是否正确响应命令

### 调试技巧：
- 先运行 `quick_test.py` 验证连接
- 检查H7串口输出确认命令执行
- 手动操作示波器确认信号存在

## 📋 使用建议

### 日常使用：
1. 使用 `simple_test.py` 进行快速验证
2. 选择"快速测试"模式获得总体评估
3. 如需特定频率测试，使用"单点测试"

### 研发验证：
1. 使用 `simple_test.py` 的频率/幅度扫描
2. 需要全面数据时使用 `RigolTest.py`
3. 用 `data_analysis.py` 分析历史数据

### 生产测试：
1. 配置标准测试点在 `simple_test.py`
2. 设置合格标准（误差阈值）
3. 批量测试并记录结果
