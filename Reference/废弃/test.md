好的，这是一个在数字信号处理和嵌入式系统领域中非常经典和实际的问题。当您用ADC采集一个正弦波信号并存为数组后，要在时域上对其进行分析，业界有多种成熟且常用的方法来检测峰值、上升沿和下降沿。

这些方法的选择通常取决于您对**精度**、**计算资源（速度）**和**抗噪声能力**的要求。

---

### 核心思想

对于一个理想的正弦波 $y(t) = A \sin(2\pi ft + \phi) + C$，其特性如下：
* **峰值 (Peak/Trough)**：发生在信号的一阶导数为零的时刻（$y'(t)=0$）。
* **上升/下降沿 (Edge)**：最陡峭的边沿发生在信号的过零点（或者说是直流偏置点），此时信号的一阶导数绝对值最大（$|y'(t)|$ is max）。

在离散的ADC数据中，我们无法直接求导，因此使用差分、比较和插值等方法来逼近这些特性。

---

### 1. 峰值检测 (Peak Detection)

峰值检测的目标是找到数组中的最大值（正峰值/波峰）和最小值（负峰值/波谷）。

#### 方法一：简单的局部极值搜索 (Simple Local Maxima/Minima Search)

这是最直接、计算量最小的方法。

* **原理**：遍历整个数据数组，如果一个点的值比它紧邻的前一个点和后一个点都大，那么它就被认为是一个正峰值。反之，如果都小，则为负峰值。
    * **正峰值条件**：`data[i] > data[i-1]` 并且 `data[i] > data[i+1]`
    * **负峰值条件**：`data[i] < data[i-1]` 并且 `data[i] < data[i+1]`

* **优点**：
    * 实现非常简单，计算速度极快。
    * 适用于噪声很小、且采样率远高于信号频率的场景。

* **缺点**：
    * **对噪声敏感**：一个小的噪声尖峰就可能被误判为峰值。
    * **精度有限**：检测到的峰值位置只能精确到某一个采样点，而真实峰值很可能落在两个采样点之间。其幅值精度也受此影响。

#### 方法二：带平滑滤波的局部极值搜索 (Smoothed Local Maxima Search)

为了解决噪声问题，通常会在检测前对信号进行平滑处理。

* **原理**：
    1.  先对原始ADC数据应用一个低通滤波器，最常用的是**移动平均滤波器 (Moving Average)**。例如，用一个3点或5点的窗口对数据进行平滑。
    2.  在平滑后的数据上再使用**方法一**进行局部极值搜索。

* **优点**：
    * 显著提升抗噪声能力，避免了毛刺引起的误判。

* **缺点**：
    * 滤波会引入**相位延迟**，导致检测到的峰值位置在时间上滞后于真实位置。
    * 滤波可能会轻微**拉低**峰值的幅度。
    * 计算量有所增加。

#### 方法三：二次/抛物线插值法 (Quadratic/Parabolic Interpolation)

这是业界用于**高精度测量**的常用方法，可以实现**亚采样点精度** (sub-sample accuracy) 的峰值检测。

* **原理**：
    1.  首先，使用**方法一**找到一个“整数位置”的峰值点，记为 `(x_n, y_n)`，其中 `x_n` 是样本序号，`y_n` 是ADC值。
    2.  取出该峰值点及其左右相邻的两个点：`(x_{n-1}, y_{n-1})`, `(x_n, y_n)`, `(x_{n+1}, y_{n+1})`。
    3.  这三个点可以唯一确定一条抛物线。我们认为这条抛物线的顶点就是对真实信号峰值的最佳逼近。
    4.  通过求解抛物线的顶点公式，可以得到峰值在时间轴上的精确偏移 `Δx` 和幅值的精确估计 `y_p`。

    假设三个点的ADC值为 $y_{n-1}, y_n, y_{n+1}$，则峰值点相对于中心点 `x_n` 的位置偏移量 `Δx` 为：
    $$
    \Delta x = \frac{1}{2} \frac{y_{n-1} - y_{n+1}}{y_{n-1} - 2y_n + y_{n+1}}
    $$
    精确的峰值位置为 $x_p = x_n + \Delta x$。

    峰值的精确幅度估计 `y_p` 为：
    $$
    y_p = y_n - \frac{1}{4} (y_{n-1} - y_{n+1}) \Delta x
    $$

* **优点**：
    * 可以获得远高于采样率的幅度和时间精度。
    * 对于正弦波这类在峰值附近形状很像抛物线的信号，效果极佳。

* **缺点**：
    * 计算比前两种方法复杂。
    * 对噪声依然敏感，通常建议在**轻度滤波后**的数据上应用此方法。

### 2. 上升沿/下降沿检测

对于正弦波，最陡峭的上升/下降沿发生在信号穿越其**直流偏置（中点）**的时刻。因此，检测边沿通常转化为检测“过零点”（Zero-Crossing）。

#### 首先：确定信号中点 (Midpoint)

如果信号有直流偏置，直接找ADC值为0的点是不对的。需要先确定信号的中心线。
* **方法**：可以通过找到正峰值 `V_p` 和负峰值 `V_t` 后计算中点：`Midpoint = (V_p + V_t) / 2`。或者对整个采集周期的数据求平均值。

#### 方法一：简单的过零点检测 (Simple Zero-Crossing Detection)

* **原理**：遍历数据，寻找一对相邻的采样点，它们的值正好跨越了信号中点 `Midpoint`。
    * **上升沿条件**：`data[i-1] < Midpoint` 并且 `data[i] >= Midpoint`
    * **下降沿条件**：`data[i-1] > Midpoint` 并且 `data[i] <= Midpoint`

* **优点**：
    * 实现简单，计算飞快。

* **缺点**：
    * 精度有限，只能定位到两个采样点之间，时间分辨率为一个采样周期。

#### 方法二：线性插值过零点检测 (Linear Interpolation for Zero-Crossing)

为了获得亚采样点精度的过零时刻，可以使用线性插值。这是频率计、锁相环等应用中的核心算法。

* **原理**：
    1.  使用**方法一**找到跨越中点的两个相邻点 `(x_{i-1}, y_{i-1})` 和 `(x_i, y_i)`。
    2.  假设这两点之间是线性的，可以根据几何关系（相似三角形）计算出精确的过零点时间 `x_zc`。

    公式如下：
    $$
    x_{zc} = x_{i-1} + (x_i - x_{i-1}) \times \frac{\text{Midpoint} - y_{i-1}}{y_i - y_{i-1}}
    $$
    由于采样时间间隔是固定的（设为1个单位），公式可以简化为：
    $$
    x_{zc} = x_{i-1} + \frac{\text{Midpoint} - y_{i-1}}{y_i - y_{i-1}}
    $$

* **优点**：
    * 提供了非常高的时间精度，是测量频率和相位的标准方法。
    * 计算量适中，在大多数微控制器上都能轻松实现。

* **缺点**：
    * 假设了两点间的线性关系，对于高频信号或低采样率场景，误差会增大。

#### 方法三：一阶差分法 (First-Order Difference)

该方法模拟了求导数的过程。

* **原理**：
    1.  计算数组的一阶差分：`diff[i] = data[i] - data[i-1]`。这个 `diff` 数组近似于原始信号的导数。
    2.  **上升沿**对应于 `diff` 数组的**最大值**所在的位置。
    3.  **下降沿**对应于 `diff` 数组的**最小值**所在的位置。

* **优点**：
    * 直观地找到了“变化最快”的点。

* **缺点**：
    * **对噪声极其敏感**。差分运算会极大地放大高频噪声，导致 `diff` 数组充满尖峰，难以找到真实的极值点。因此，**强烈建议**在对原始数据进行**有效平滑滤波后**再使用此方法。

### 总结与业界实践推荐

| 检测目标 | 方法 | 优点 | 缺点 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **峰值检测** | **1. 简单局部极值** | 速度最快，实现简单 | 精度低，怕噪声 | 噪声极小，资源有限的MCU |
| | **2. 平滑+局部极值** | 抗噪声能力强 | 引入延迟和幅度衰减 | 通用场景，对噪声有一定要求 |
| | **3. 抛物线插值** | **精度最高** (幅度和时间) | 计算复杂，需先定位 | **精密测量仪器**，如数字示波器、功率分析仪 |
| **边沿检测** | **1. 简单过零检测** | 速度最快，实现简单 | 精度低（一个采样周期） | 粗略的同步或触发 |
| | **2. 线性插值过零** | **精度最高** (时间) | 计算量稍大 | **频率/相位测量**，锁相环，精密同步 |
| | **3. 一阶差分** | 原理直观 | 对噪声极度敏感 | 不常用，除非配合强大的滤波 |

**业界最佳实践组合 (Best Practice):**

1.  **预处理**: 对原始ADC数据进行一次**移动平均**或更高级的低通滤波（如FIR滤波器），以抑制噪声。滤波器的长度需要权衡，太长会引入过大的延迟和波形失真。
2.  **估算中点**: 对滤波后的数据计算峰值和谷值的平均，得到精确的 `Midpoint`。
3.  **高精度峰值检测**: 在滤波后的数据上，先用**局部极值搜索**找到整数位置的峰值，然后用**抛物线插值法**计算亚采样点精度的峰值幅度和位置。
4.  **高精度边沿检测**: 在滤波后的数据上，先用**简单过零检测**找到跨越 `Midpoint` 的点对，然后用**线性插值法**计算亚采样点精度的过零时刻。

这个组合兼顾了抗噪声能力和高精度，是大多数现代数字测量仪器中时域分析算法的基础。
